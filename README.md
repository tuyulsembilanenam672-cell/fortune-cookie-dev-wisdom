One original fortune-cookie line for a software developer, written by a program (`main.ts`) that outputs it to `/output/entry.txt`:

> The test that never fails is the test that never tests.

A balanced, single-breath fortune: true about a developer's day, with a quiet twist on the word "tests" that rewards a second read. Built for the [make.fun bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).
